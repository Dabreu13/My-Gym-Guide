MY GYM GUIDE — VERSION 2 STARTER
Upload index.html, manifest.webmanifest, sw.js, and icon.svg to the repository root. Replace the previous index.html. Keep GitHub Pages set to main / root.
Open the site online, refresh once, then test airplane mode. External references require internet.
Features: 3/5-day selector, local workout history, set logging, rest timer, JSON backup and restore, offline caching.
Limitations: no verified videos, no animated exercise demonstrations or picture sequences, no automatic substitutions, no cloud sync. This is a functional starter, not the completed visual library. Do not use mismatched original illustrations.
Data is local to the browser. Keep exported backups private. Do not commit personal logs or photos.
Template: 2 working sets of 8–12 repetitions. General adult starter, not individual medical advice. Ask staff to confirm equipment setup. Do not exercise through worsening pain.
Sources: ACSM https://acsm.org/wp-content/uploads/2026/03/Resistance-Training-Position-Stand-infographic.pdf ; ACE https://www.acefitness.org/resources/everyone/exercise-library/ ; exact exercise references within app.
Testing: files generated and internal exercise references checked; not browser- or iPhone-tested. Verify before relying on storage or offline availability.
